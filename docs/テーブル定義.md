### カラム定義

| カラム名 | 型 | PK | FK | NULL | UNIQUE | デフォルト | 説明 |
|----------|----|----|----|------|--------|------------|------|
| id | BIGSERIAL | ○ | | × | - | | ユーザーID |
| name | VARCHAR(50) | | | × | | | ユーザー名 |
| email | VARCHAR(255) | | | × | ○ | | メールアドレス |
| password | VARCHAR(255) | | | × | | | ハッシュ化したパスワード |
| created_at | TIMESTAMP | | | × | | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | | | × | | CURRENT_TIMESTAMP | 更新日時 |

### リレーション

| テーブル | 関係 |
|----------|------|
| cars | 1対多 |

### インデックス

| カラム | 理由 |
|---------|------|
| email | ログイン時の検索を高速化 |
