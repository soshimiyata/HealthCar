- 費用を可視化する
- カスタム履歴を残す

# Phase1

## メンテナンス管理

- 整備履歴を管理する
- 交換した時期を忘れない
- 次回交換距離・日付を表示する
- メンテナンス費用を管理する

---

## カスタム管理

- カスタム履歴を残す
- パーツの種類を管理する
- メーカーを管理する
- パーツ価格を記録する

---

# Phase2
## 車両情報管理

- 車高（フロント・リア）を記録する
- ホイールサイズ
- タイヤサイズ
- アライメント値（キャンバーなど）
- 走行距離

## DIY支援

例

```
車高調交換

↓

必要工具

・ジャッキ
・ウマ
・17mmソケット
・19mmメガネ
・トルクレンチ
```

これが出ると実用的。

さらに

```
持っている工具

✔ トルクレンチ
✔ ジャッキ

持っていない

□ スプリングコンプレッサー
```

みたいな表示ができる。
